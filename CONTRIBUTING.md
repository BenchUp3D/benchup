# Contributing to BenchUp

Submit changes through a pull request to
[BenchUp3D/editor](https://github.com/BenchUp3D/editor). Describe the problem,
the change, and any verification you performed. Keep unrelated changes separate.

## Contributor License Agreement

Before your first contribution can be merged, read the
[BenchUp Contributor License Agreement, version 1.0](CLA.md) and post this
statement as a comment on your pull request from your own GitHub account:

> I have read and agree to the BenchUp Contributor License Agreement, version 1.0, and I have the authority to grant the licenses described in it.

This comment is your electronic signing statement. Your GitHub account and the
comment's timestamp provide the public acceptance record. Do not post a private
address, email address, or handwritten signature.

If you sign on behalf of an organization, also identify the organization and
state that you are authorized to bind it. If your employer owns rights to the
work, obtain its authorization before signing or submitting that work.

Each contributor to a pull request must sign from their own account. A pull
request author cannot sign for other individuals. Once accepted, version 1.0
covers your future contributions as described in the agreement; you do not need
to sign again for every pull request.

Maintainers must verify each contributor's acceptance before merging and keep
a link to any earlier signing comment in the pull request being reviewed.
Verification is manual; this repository does not automatically check signatures
or block merges for missing signatures.

Contributors retain ownership of their work. The Project uses the
[MIT License](LICENSE). Identify third-party material, its source, and its
license in the pull request.
