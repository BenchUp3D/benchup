# Native SketchUp reader

`benchup-skp` owns the C/C++ build and exposes a safe `parse` function that returns
BenchUp model JSON or a structured reader error. `benchup-io` handles model
validation, face normalization, and user-facing error messages. The app depends
on the reader through `benchup-io`; no UI or server/update configuration is part
of this crate's build inputs.

`vendor/openskp/` contains the parsing/model/JSON source subset and public headers
from OpenSKP commit `23a15e8742e936694bf14aa029cb0e2862dce5b9` (MIT, see
`vendor/LICENSE-openskp`). Unused exporters are not compiled.
`vendor/openskp/include/openskp/export.hpp` is the static-library export shim
normally generated by upstream CMake.

`vendor/openskp/miniz/` contains miniz source from commit
`77d0dce8627735138c51770d1799a1ef48f2117d`, pinned by upstream's CMake file;
its MIT license is in `vendor/openskp/miniz/LICENSE`. `miniz_export.h` is its
static export shim. BenchUp's C ABI and topology adapter are in
`src/skp_native.cpp`.

Cargo's `cc` build dependency compiles these local sources without network access,
using C++17 and Cargo's jobserver to bound parallel compilation. Browser app
builds do not depend on this crate. For workspace-wide WebAssembly checks, its
build script skips native compilation and its Rust library is empty.
