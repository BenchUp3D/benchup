# BenchUp documentation

Guides for using the desktop and browser editor.

- [Desktop installation and updates](desktop.md): packaged releases, automatic updates, and release notes.
- [Controls and modeling](controls.md): keyboard shortcuts, navigation, drawing, measurements, objects, and solid tools.
- [Right sidebar and preferences](sidebar.md): Outliner, Components, Tags, Display, and remembered settings.
- [Build with MIRA](assistant.md): the plain-language design assistant, references, undo, and the detachable panel.
- [Projects, import, export, and recovery](projects.md): saving projects, SketchUp import, OBJ export, autosave, and undo history.

For development setup, building, testing, and deployment, see the [developer README](../README.md).

Contributing to Build with MIRA? See the [MIRA contributor documentation](mira/README.md): architecture, tool catalog, LLM protocol, security, testing, and recipes for extending the assistant.
